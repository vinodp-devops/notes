Convert Existing Folder to Repo
==================================
- Initaly you should have folder in local
- If you created repo in Git then,
- redirect to folder and use commands
	=> git init
	=> git branch -M main (change master to main)
	=> git remote add origin https://github.com/vinodp-devops/ansible.git
	=> git add .; git commit -m "ansible"; git push origin main
	
-i is for Inventory
	
ansible frontend  -i inventory.ini --list-hosts
ansible backend   -i inventory.ini --list-hosts
ansible all 	  -i inventory.ini --list-hosts
ansible roboshop  -i inventory.ini --list-hosts
ansible ungrouped -i inventory.ini --list-hosts
ansible-inventory -i inventory.ini --graph
ansible-inventory -i inventory.ini --list
	
ansible is developed in Python

we give inputs in playbook, ansible runs inside Python connect to the systems using API


ansible-playbook -i inventory.ini -e ansible_user=ec2-user -e ansible_password=DevOps321 01-playbook.yaml
