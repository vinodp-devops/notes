sed editor -> streamline editor

insert text after line 1

sed '1a Hi' users -> add the text after line 1, temporary edit only on screen. for perm use -i option

sed '1i Hello' users -> before line 1 temporary
sed -i '1i Hello' users -> before line 1 permanent

sed '2d' users -> delete 2nd line in users temporary
sed -i '2d' users -> delete 2nd line in users permanent

sed '/sbin/d' users -> delete /sbin/ in users temporary
sed -i '/sbin/d' users -> delete /sbin/ in users permanent

Replace line
--------------
sed 's/sbin/SBIN/g' users -> Replace sbin as SBIN and 's' is substitute 'g' is global
sed '2s/sbin/SBIN/g' users -> Replace sbin in 2nd line as SBIN 

sed -i 's/sbin/SBIN/g' users -> Replace sbin as SBIN and 's' is substitute 'g' is global
sed -i '2s/sbin/SBIN/g' users -> Replace sbin in 2nd line as SBIN
